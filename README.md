# Apolo — Armário Virtual

O **Apolo** é uma plataforma web desenvolvida com o objetivo de unir **moda e tecnologia**, permitindo que os usuários organizem suas peças de roupa e criem combinações de outfit de forma prática e personalizada.

A proposta do projeto é funcionar como um **armário virtual**, no qual o usuário pode visualizar suas peças, montar outfits e salvar suas combinações para consultar posteriormente.


## Sobre o projeto

O Apolo foi desenvolvido como um projeto de desenvolvimento web com foco em **personalização, praticidade e interação do usuário**.

A plataforma permite que o usuário monte seus próprios outfits utilizando diferentes peças, como:

- 👕 Camisas
- 🩳 Shorts
- 👟 Tênis

Após montar uma combinação, o usuário pode salvá-la e posteriormente visualizar seus outfits através do **Closet**.


## Objetivo

O principal objetivo do Apolo é facilitar o processo de escolha de roupas, permitindo que o usuário:

- Crie diferentes combinações de roupas;
- Visualize suas peças de forma organizada;
- Monte e salve seus próprios outfits;
- Consulte posteriormente os looks salvos;
- Explore diferentes possibilidades de estilo;
- Tenha acesso às suas combinações de qualquer lugar.

## Peças de roupa

Para inserir as peças utilizadas no sistema, foram realizadas fotografias de roupas reais.

Para obter imagens mais padronizadas e com melhor qualidade, foram utilizados equipamentos como:

- Ring light;
- Tripé;
- Mesa plana.

A utilização desses equipamentos ajudou a produzir imagens mais nítidas e reduzir deformações nas peças fotografadas.
